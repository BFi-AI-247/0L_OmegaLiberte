# Fact-check prompt (v1)
**System** (same as [dialog](dialog.md), plus the item)
**User**
> Check the core claims of this item briefly: what is supported, what is questionable, what is opinion, satire or humour (joke, comedy, irony, entertainment)? End with exactly one line "Verdict: confirmed", "Verdict: questionable", "Verdict: misleading", "Verdict: satire/humour" or "Verdict: not checkable".
