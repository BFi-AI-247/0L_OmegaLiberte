# Shared formats
The only fixed agreements between OmegaLiberte instances. Everything else may differ. All formats are JSON (UTF-8). Add fields freely; never change the meaning of existing ones.

| Format | Purpose |
|---|---|
| [source-pack](source-pack.md) | A set of sources to import (also: OPML is accepted) |
| [catalog](catalog.md) | Verified starter sources of an instance, in groups, one file per language |
| [curation](curation.md) | The AI's selection: topics, picked items, reasons |
| [fact-check](fact-check.md) | Verdict on one item |
| [logbook-entry](logbook-entry.md) | One change and why it was made |
